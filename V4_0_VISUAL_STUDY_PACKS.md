# Version 4.0 — Verified Visual Study Packs

## One answer, three study surfaces

1. The reviewed answer remains in Quick Solver.
2. A colorful A4 PDF is generated for reliable download, printing and revision.
3. An animated offline HTML lesson is generated for phones and computers.

PDF animation is not promised because standard PDF viewers commonly block or ignore
embedded animation. The matching HTML contains safe CSS/SVG animation and no generated
scripts, external assets or API dependency.

## Subject intelligence

- Mathematics: exact-expression calculator and derivation checks.
- Physics: signs, units, dimensions, assumptions, conservation laws and formulas.
- Chemistry: carbon skeleton, functional groups, reagents and named-test requirements.
- Biology: scale, structure-function, pathways, terminology and exceptions.
- Geography: coupled ocean-atmosphere-orography mechanisms and scope qualifiers.
- History/Civics/Economics: names, dates, chronology, mechanisms and interpretations.
- Language/Literature: grammar, meaning, textual evidence and interpretation labels.

Long factual or technical questions use a second independent examiner. Factual web
verification is an explicit checkbox because it sends the typed question to Google
Search through Gemini; uploaded private documents are never included in that request.

## Visual routing

Dedicated templates currently cover volcanoes, coastal climate/rain shadow systems,
charged-ring electrostatics and cells. Every other topic receives a subject-colored
concept map showing core idea, mechanism and application. All model text is escaped
before entering downloaded HTML, and SVG structure is generated only by trusted server
templates.
